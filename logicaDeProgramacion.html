La tienda de Don Código

Don codigo tiene una tienda y necesita una herramienta para registrar sus ventas diarias y obtener rapidamente datos clave al final del día.

Pasos a Seguir

1. ¿Cuántas ventas? 📊

Primero, el programa debe preguntar al usuario la cantidad total de productos vendidos en el día.

2. Almacenar Valores 💾

Se creará un espacio (un arreglo) para guardar el valor de cada una de las ventas registradas.

3. Registrar Cada Venta ✍️

Mediante un ciclo, se solicitará el valor de cada venta una por una, guardando cada dato en el espacio creado.
